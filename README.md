# Fundy Banjos

Website for [Fundy Banjos](https://www.fundybanjos.com), a small workshop in the Annapolis Valley, Nova Scotia, building open-back banjos for old-time and clawhammer music. Built by Alex Nemet.

**Live site:** https://www.fundybanjos.com

- [Banjo models](https://www.fundybanjos.com/banjo-models.html): the Tidal and High Tide, plus bespoke builds
- [Custom banjo gallery](https://www.fundybanjos.com/custom-banjo-gallery.html): past one-off instruments
- [Fundy Tuner](https://www.fundybanjos.com/fundy-tuner.html): a free tuner app for clawhammer and old-time players
- [Contact](https://www.fundybanjos.com/contact.html)

## About this repo

A hand-written static site (HTML, CSS and a little JavaScript, no build step), hosted on GitHub Pages. Pages live at the top level, images under `img/`, and shared styles in `styles.css`. A few older page names (like `red_banjo.html`) are kept as redirects so old links keep working.
